# Environment variables

Templates contain placeholders only. Ignored .env/.env.testing/.env.local files contain local settings; credentials are never printed in setup output. Select native development via python3 scripts/setup-env.py --profile native (or --profile compose); generate backend APP_KEY with php artisan key:generate. Production secrets belong to a secret manager and are not configured in this phase.

| Category | Variables | Boundary |
|---|---|---|
| Application | APP_NAME, APP_ENV, APP_KEY, APP_DEBUG, APP_URL | Local environment explicit; debug false by default; production guard requires HTTPS/debug off |
| Frontend trust | FRONTEND_URL, TRUSTED_ORIGINS, SANCTUM_STATEFUL_DOMAINS | Explicit origins/host:port; no wildcard; local http://localhost:3000 is local-only |
| PostgreSQL | DB_CONNECTION, DB_HOST, DB_PORT, DB_DATABASE, DB_USERNAME, DB_PASSWORD, DB_SSLMODE | pgsql only; native local 5432 / iranti, Compose 54320 / iranti_app; production requires approved TLS settings; separate test role/database |
| Sessions | SESSION_DRIVER, SESSION_LIFETIME, SESSION_ENCRYPT, SESSION_SECURE_COOKIE, SESSION_HTTP_ONLY, SESSION_SAME_SITE, SESSION_DOMAIN | PostgreSQL intended; secure/HttpOnly/Lax/encrypted defaults; local HTTP explicitly overrides secure=false; schema/session/CSRF flows implemented in approved Phase 3B |
| Redis queue | REDIS_CLIENT, REDIS_HOST, REDIS_PORT, REDIS_PASSWORD, REDIS_DB, REDIS_PREFIX | Predis; local loopback 63790, noeviction |
| Redis cache | REDIS_CACHE_HOST, REDIS_CACHE_PORT, REDIS_CACHE_PASSWORD, REDIS_CACHE_DB | Separate process, local 63791; production credentials/private network required |
| Queue/cache | QUEUE_CONNECTION, REDIS_QUEUE, REDIS_QUEUE_RETRY_AFTER, QUEUE_FAILED_DRIVER, CACHE_STORE | redis queue/cache; retry_after 90 seconds, local worker/media timeout 60; failed jobs PostgreSQL |
| Mail | MAIL_MAILER, MAIL_HOST, MAIL_PORT, MAIL_USERNAME, MAIL_PASSWORD, MAIL_SCHEME, MAIL_FROM_ADDRESS, MAIL_FROM_NAME | Array for local tests; SMTP for real delivery; identity recovery rejects log mail |
| Storage | FILESYSTEM_DISK, AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_DEFAULT_REGION, AWS_BUCKET, AWS_ENDPOINT, AWS_USE_PATH_STYLE_ENDPOINT | Local private disk now; S3 abstraction installed, no live bucket/provider |
| Logging | LOG_CHANNEL, LOG_LEVEL | JSON stderr, no raw exception/request secrets |
| Frontend public | NEXT_PUBLIC_API_URL | /api/v1 only; public variables are visible to browsers, never secrets |
| Frontend server | API_INTERNAL_URL | HTTP(S) origin without path/credentials; proxy upstream, never exposed as public secret |
| Tests | IRANTI_INFRA_TESTS | Explicit 1 enables destructive operations only in disposable iranti_test DB with guards |
| Compose credentials | POSTGRES_ADMIN_PASSWORD, POSTGRES_APP_PASSWORD, POSTGRES_TEST_PASSWORD | Generated infrastructure/.env, different local roles, never committed |

Browser clients use same-origin /api/v1. Public variables cannot carry credentials. FRONTEND_URL records intended frontend origin; CORS is controlled by explicit TRUSTED_ORIGINS. Stateful Sanctum/session middleware and CSRF endpoints are active under the approved Phase 3B baseline.

Production additionally requires trusted proxy configuration, cookie review, mail/storage/provider credentials, private service networking/TLS, retention and deployment approval. No production-ready configuration or security certification is claimed.

Everyday macOS development uses the persistent Homebrew PostgreSQL 18 cluster and two Homebrew-backed Redis LaunchAgents. Existing tests remain isolated from iranti_local. Native project-role TCP authentication uses SCRAM; Redis remains loopback-only. See the authoritative [local setup](local-setup.md). No production configuration is implied.

## Catalog additions
`CATALOG_DISK` selects local or private S3 storage. `CATALOG_MEDIA_ORIGIN` is an owned HTTPS CDN proxying the controlled API media route, never an open bucket prefix. `CATALOG_INTERNAL_READ_KEY` is a shared private Next/API read-budget key generated by setup; never expose it through NEXT_PUBLIC. `SITE_URL` is the actual canonical storefront origin. See [media configuration](product-media.md) for PHP/ingress limits, workers and vendor gates.

## Cart additions
`CART_MAX_QUANTITY=99`, `CART_MAX_LINES=100`, and `CART_GUEST_RETENTION_DAYS=30` are client-approved configurable engineering defaults. Keep positive integer values and review changes against existing carts; only user-less carts are subject to guest cleanup. The encrypted guest cookie follows existing `SESSION_SECURE_COOKIE` configuration. No new cart secret or Redis persistence database is required. See [cart operations](cart.md).

## Phase 3F checkout

No tax percentage or delivery price is inferred from environment defaults. Operators publish complete immutable database configuration through the protected owner/MFA API described in [tax.md](tax.md). The development example is opt-in and forbidden in production. Checkout reuses the existing inventory reservation TTL (900 seconds by default), session/cookie security, PostgreSQL and scheduler configuration; no additional Redis instance or external logistics service is required. No new real secret is present in tracked examples.

## Phase 3G orders

`ORDER_GUEST_ACCESS_SECONDS=86400` is the client-approved configurable default for the initial order-scoped guest capability. Accepted configuration range: 1..604800 seconds. Expiry is absolute from placement; reads/replays cannot renew it. No real credential or provider setting is added. An encrypted path-scoped cookie grants only that order; email recovery is deferred by explicit client approval.

## Phase 3I tracking host configuration

`SHIPPING_TRACKING_HOSTS` is a non-secret comma-separated list of exact approved lowercase HTTPS carrier hostnames. Default: empty (fail closed for tracking links and dispatch). No scheme/path/port/wildcard. Client/logistics must approve the actual hosts; do not infer one from the carrier name. See [shipping.md](shipping.md). No frontend tracking configuration or carrier API secret is required for manual fulfilment.
