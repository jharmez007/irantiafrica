## Free-service design

Use one Free Docker Web Service and this one Free PostgreSQL database. Nginx, PHP-FPM, standalone Next.js, one database queue worker and one `schedule:work` process run in the approved container. Use its private, same-region database URL in Render configuration. Set `QUEUE_CONNECTION=database`, `CACHE_STORE=database`, `RATE_LIMIT_CACHE_STORE=database`, and `SESSION_DRIVER=database`; do not provision Redis. Keep `APP_ENV=production` inside the container for the existing fail-closed guards while labeling the deployment and all data **TEST ONLY**. Set `APP_DEBUG=false`, secure/HttpOnly/encrypted database sessions, `PAYSTACK_MODE=test`, `PAYSTACK_LIVE_APPROVED=false`, `PAYMENTS_ENABLED=false` initially, `TRANSACTIONAL_EMAIL_ENABLED=false` initially, and `PRELAUNCH_GATE_ENABLED=true`. Use a unique test-only `APP_KEY`, renderer key and Basic Auth credential in Render private environment settings. Use only TEST Paystack keys and a test inbox. Never copy final production secrets or owner credentials into this temporary environment.

The desired HTTPS origin is `https://iranti-africa-free-test.onrender.com` if Render assigns that hostname. Confirm the actual URL before setting `SITE_URL` (build-time), `APP_URL`, `FRONTEND_URL`, `TRUSTED_ORIGINS`, `SANCTUM_STATEFUL_DOMAINS` (hostname only), and `CATALOG_MEDIA_ORIGIN`. `API_INTERNAL_URL=http://127.0.0.1:8080` and `NEXT_PUBLIC_API_URL=/api/v1` remain same-container/same-origin. Use `FILESYSTEM_DISK=s3`, `CATALOG_DISK=s3`, `CATALOG_UPLOAD_TRANSPORT=proxy`, `AWS_DEFAULT_REGION=auto`, `AWS_USE_PATH_STYLE_ENDPOINT=true`, a **private** R2 Standard bucket, scoped Object Read & Write credentials and its HTTPS S3 endpoint. Never enable public R2 bucket access.
