# Phase 3N inventory modal UAT evidence

Developer browser verification: 2026-09-27, using synthetic owner and inventory records in an isolated local QA stack. No real customer data or provider credentials appear in these captures. The circular Next.js development indicator is a development-only overlay.

| Evidence                                                     | What it shows                                                                                                                                                                     |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Adjust 320px](adjust-320.png), [1440px](adjust-1440.png)    | Product/SKU context, compact stock summary, signed-number form, separate Cancel and Review actions; no history                                                                    |
| [Review 375px](review-375.png)                               | Quantity/result/reason/SKU review with spaced secondary Cancel review and primary Confirm                                                                                         |
| [History 320px](history-320.png), [1440px](history-1440.png) | Separate movement table, product/SKU context and pagination; table scroll stays inside the modal on narrow screens                                                                |
| [Responsive results](responsive-results.json)                | Loaded Adjust and History dialogs at 320, 375, 768, 1024 and 1440px: viewport bounds, document overflow, focus containment, semantic headings/columns and axe A/AA/2.1 AA results |

The five-width browser pass found no document-level horizontal overflow or axe violations in either dialog. Cancel closed Adjust and returned focus; Escape closed History and returned focus. An additional browser check passed History backdrop close/focus return. The signed integer input rejected letters and exponent notation, accepted `-2`, and exposed its hint through `aria-describedby`. A mobile review/cancel/reopen check found no stale quantity, reason or review state. A synthetic successful adjustment closed the modal, showed success feedback and refreshed inventory. POST failure, retry-key and conflict behavior were covered by frontend tests; the existing backend integer and stock-integrity suite passed unchanged.
